## 🚀 Installation

1. **Install BepInEx 5.4+** for Gorilla Tag
2. **Download** the latest PNGSUS release
3. **Extract** to your `BepInEx/plugins` folder
4. **Launch** Gorilla Tag
5. **Press M** to open PNGSUS

## 📝 Usage

### Opening the Menu
```
Press M key to toggle the mod menu
```

### Navigating Categories
```
Press Q to go to previous category
Press E to go to next category
Or click the category tabs directly
```

### Navigating Pages
```
Use RIGHT/LEFT arrows or D/A keys to switch pages
Or use the Previous/Next Page buttons
```

### Finding Mods
```
Press Ctrl+F to open search
Type mod name to filter results
Results appear in real-time
```

### Toggling Mods
```
Select mod with up/down arrow keys
Press Enter or Space to enable/disable
Or click the toggle button
Button turns green when enabled, red when disabled
```

### Marking Favorites
```
Press Ctrl+B to show only favorites
Or click the star icon on individual mods
⭐ = Favorite
☆ = Not favorite
```
